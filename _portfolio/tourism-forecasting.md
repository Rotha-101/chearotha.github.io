Tools & Skills: Python (Pandas, NumPy, Matplotlib), ARIMA, SARIMA, Prophet, LSTM, Time Series Modeling

Project Overview
======
This project focused on analyzing historical tourism data to forecast future arrival trends in Cambodia, providing actionable insights for post-pandemic recovery planning.

Analytical Approach
======
* **Data Preprocessing**: Cleaned and transformed raw arrival data into a consistent time-series format, handling seasonal fluctuations.
* **Model Selection**: Evaluated various statistical and machine learning models for forecasting accuracy:
    * **ARIMA/SARIMA**: For capturing linear trends and seasonality.
    * **Prophet**: For handling holidays and non-linear growth.
    * **LSTM**: For deep learning-based sequence prediction.
* **Evaluation**: Utilized Mean Squared Error (MSE) and residual diagnostics to validate model robustness.
* **Strategic Insights**: Identified key recovery drivers and seasonal patterns, helping policymakers align resource allocation with expected peaks in tourism.
