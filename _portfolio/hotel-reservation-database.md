Role: Database Designer & Developer
Tools & Skills: MySQL, SQL, ERD Design, Relational Database Modeling

Project Overview
======
Designed a comprehensive database system to streamline hotel operations, focusing on booking management, client tracking, and staff scheduling.

Technical Implementation
======
* **ERD Design**: Created detailed Entity-Relationship Diagrams (ERD) to visualize the relationships between Clients, Rooms, Services, Bookings, and Staff.
* **Schema Development**: Built relational schemas ensuring data integrity and reducing redundancy through normalization (up to 3NF).
* **Constraints**: Applied primary and foreign key constraints, along with triggers for automated status updates.
* **Workflow Support**: Developed optimized SQL queries to support front-end workflows, including room availability checks and payment verification.
* **Data Integrity**: Implemented ACID properties to ensure reliable transaction processing during high-concurrency booking events.
