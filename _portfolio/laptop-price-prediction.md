Role: Data Analyst & Model Developer
Tools: Python, Pandas, Scikit-learn, BeautifulSoup, Matplotlib, Seaborn

Project Overview
======
This project aimed to build a robust predictive model for laptop prices based on various hardware specifications. The data was scraped and cleaned to ensure high-quality input for the machine learning models.

Key Contributions
======
* **Data Acquisition**: Utilized `BeautifulSoup` to scrape laptop pricing and specification data from e-commerce platforms.
* **Exploratory Data Analysis (EDA)**: Conducted thorough EDA to identify key price drivers such as CPU brand, RAM capacity, and GPU type.
* **Feature Engineering**: Transformed categorical variables and handled missing values to improve model performance.
* **Modeling**: Implemented and compared multiple regression models, including:
    * Linear Regression
    * Random Forest Regressor
    * Support Vector Regressor (SVR)
* **Performance**: Achieved high prediction accuracy with the Support Vector Regressor model through hyperparameter tuning.
