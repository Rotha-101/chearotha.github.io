Tools & Skills: Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn, Jupyter Notebook

Project Overview
======
Developed a data-driven system to assist farmers in maximizing agricultural output by predicting yields and recommending the most suitable crops based on environmental conditions.

Key Features
======
* **Data Integration**: Merged agricultural datasets containing soil parameters (NPK, pH) and weather factors (temperature, rainfall).
* **Advanced Modeling**: Built and tuned high-performance models using **Random Forest** and **XGBoost** to predict yield per hectare.
* **Feature Importance**: Engineered features from climatic data to identify the most critical factors affecting specific crop varieties.
* **Recommendation Engine**: Developed a logic-based recommendation system that suggests the top 3 crops for a given land area based on real-time environmental inputs.
* **Impact**: Provided a tool to reduce agricultural risk and improve food security through informed decision-making.
